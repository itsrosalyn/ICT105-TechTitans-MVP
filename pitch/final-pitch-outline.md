# Slide 2: Problem and Target Users

## Problem

Manual attendance recording wastes valuable class time and allows proxy attendance, where students ask others to record attendance on their behalf. Lecturers also spend additional time managing attendance records and calculating attendance percentages manually.

## Target Users

### Students
- Need a fast and convenient way to record attendance using their smartphones.
- Want to view their attendance history and attendance percentage.

### Lecturers
- Need an efficient way to generate QR codes for attendance sessions.
- Need to reduce proxy attendance.
- Need an easier way to monitor attendance records and attendance summaries.

# Slide 4: Solution and Value Proposition

## AttendQR

AttendQR is a web-based **QR Code Attendance System with GPS Verification** developed using **HTML, CSS, JavaScript, and Firebase**.

## Key Features

- User registration and login
- QR code attendance
- GPS location verification
- Attendance confirmation
- Attendance history
- Attendance percentage tracking
- QR code generation
- Lecturer dashboard
- Attendance summaries and analytics

## Value Proposition

### For Students

- Faster attendance recording.
- Convenient attendance process using smartphones.
- Easy access to attendance history and attendance percentage.

### For Lecturers

- Reduces manual attendance work.
- Helps discourage proxy attendance.
- Provides attendance summaries and analytics through the lecturer dashboard.

# Slide 5: Final Prototype Demonstration Flow

1. Open the AttendQR Landing Page.
2. Click **Try Demo**.
3. Register a new account or log in.
4. Student scans the classroom QR code.
5. Complete GPS verification.
6. Display the attendance confirmation page.
7. View attendance history and attendance percentage.
8. Log in as a lecturer.
9. Generate a QR code for a class session.
10. View the lecturer dashboard with attendance summaries and analytics.

## Technologies Used

- HTML
- CSS
- JavaScript
- Firebase Authentication
- Firebase Firestore
- GitHub
- Netlify

## System Workflow

Student Login

↓

QR Code Scan

↓

GPS Verification

↓

Attendance Record

↓

Firebase Firestore

↓

Attendance History

↓

Lecturer Dashboard

↓

Monitor Attendance Records

## Responsible Data Handling

- Firebase Authentication securely manages user accounts.
- Firebase Firestore stores attendance records in real time.
- GPS location is used only during attendance verification.
- The system only collects data necessary for attendance recording.
- Lecturer and student functions are separated to protect attendance records.
