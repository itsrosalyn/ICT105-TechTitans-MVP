# Demo Outline for Final Pitch

## 1. Opening Problem

Manual attendance recording wastes valuable class time and allows proxy attendance, where students ask others to check in on their behalf. Lecturers also spend additional time managing attendance records and calculating attendance percentages manually. AttendQR was developed to provide a faster, more accurate, and more secure attendance process using QR code scanning and GPS verification.

## 2. Target User

- Students who need a quick and convenient way to record classroom attendance using their smartphones.
- Lecturers who need to generate attendance sessions, reduce proxy attendance, and monitor attendance records efficiently.

## 3. Product Solution

AttendQR is a web-based QR Code Attendance System with GPS Verification developed using HTML, CSS, JavaScript, and Firebase. Students can register or log in, scan a QR code, verify their classroom location using GPS, and view their attendance history and attendance percentage. Lecturers can generate QR codes, create attendance sessions, and monitor attendance records and analytics through a dashboard.

## 4. Demo Flow

1. Homepage / landing page
   - Introduce the AttendQR landing page and explain the project's purpose and key benefits.
   - Click **Try the Demo** to open the working prototype.

2. Main user action
   - Register a new account or log in as a student.
   - Navigate to the student home page.

3. Form submission
   - Demonstrate QR code scanning.
   - Complete GPS verification.
   - Show the attendance confirmation page.

4. Search/filter/list
   - Open the Attendance History page.
   - Demonstrate searching or filtering attendance records.
   - Show attendance percentage and attendance status.

5. Detail/status
   - Display attendance details for each record.
   - Explain attendance statuses such as Present, Late, and Absent.

6. Admin/update
   - Log in as a lecturer.
   - Generate a QR code for a new attendance session.
   - Display the lecturer dashboard.
   - Explain that lecturers can monitor attendance records and analytics but **cannot edit or modify recorded attendance history**.

7. Dashboard/summary
   - Demonstrate dashboard statistics, including total attendance sessions, total attendance records, attendance percentage, and attendance status distribution.
   - Show attendance analytics retrieved from Firebase.

## 5. Evidence

- **Customer discovery evidence:**
  - Interviews and discussions with ICT students and lecturers identified that manual attendance is time-consuming, vulnerable to proxy attendance, and difficult to manage efficiently.

- **Validation/testing evidence:**
  - MVP prototype testing and usability feedback were collected to evaluate the attendance workflow, navigation, and user interface before final implementation.

- **Startup/product metrics:**
  - Landing page views
  - CTA clicks
  - Demo attempts
  - Feedback responses
  - Interest conversion rate

## 6. Closing Value Message

AttendQR makes classroom attendance faster, more accurate, and more secure through QR code scanning and GPS verification. The system reduces manual work for lecturers, discourages proxy attendance, and provides students with a simple and convenient way to record attendance while supporting real-time attendance monitoring and analytics.
