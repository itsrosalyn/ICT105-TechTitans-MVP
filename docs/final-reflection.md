# Final Reflection

## 1. What We Built
We built AttendQR, a QR Code Attendance System with GPS Verification. The prototype allows lecturers to generate QR codes and students to check in quickly while reducing proxy attendance.

## 2. What We Learned About Users
From interviews and user testing, we learned that students want a faster and easier attendance process, while lecturers need a more accurate and reliable way to record attendance.

## 3. What We Learned About Requirements
We learned that clear and traceable requirements are important. Every feature should be connected to user needs and tested before implementation.

## 4. What We Improved After Testing
After user testing, we improved the navigation, attendance workflow, confirmation messages, and overall usability based on user feedback.

## 5. What Was Difficult Technically
The most difficult part was implementing GPS verification and ensuring that the prototype worked smoothly while keeping the system simple.

## 6. What We Would Improve Next
In the future, we would improve GPS accuracy, add detailed attendance reports, support more courses, and integrate with the university system.
