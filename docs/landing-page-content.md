# Landing Page Content

## Project Title

AttendQR – QR Code Attendance System with GPS Verification

## Target User

University students and lecturers at Rangsit University.

## Headline

Fast, Secure, and Accurate Attendance with QR Code and GPS Verification.

## Subheadline

AttendQR helps students check in quickly using QR codes while allowing lecturers to manage attendance more efficiently with GPS verification and real-time attendance records.

## Problem Statement

Manual attendance takes valuable class time and may allow proxy attendance. During Lab 03 customer discovery, students and lecturers reported that attendance checking is time-consuming and manual corrections are often needed. Lab 08 prototype validation also showed positive user feedback, with a 100% task success rate and an average satisfaction score of 4.7/5, indicating that the prototype is easy to use.

## Solution Description

AttendQR provides a simple attendance system where lecturers generate a QR code and students scan it with GPS verification. The system confirms attendance immediately and allows users to view attendance records efficiently.

## Key Features

| Feature | Requirement ID | User Value | Prototype Screen/Module |
| --- | --- | --- | --- |
| User Login | FR-01 | Secure access for students and lecturers | Login Page |
| QR Code Generation | FR-03 | Lecturers can generate a unique attendance QR code | Lecturer Dashboard |
| QR Code Check-in | FR-05 | Students can check in quickly without manual attendance | Student Check-in |
| GPS Verification | FR-06 | Prevents attendance from unauthorized locations | GPS Verification Module |
| Attendance History | FR-08 | Students and lecturers can view attendance records | Attendance Records |

## Benefits

- Saves classroom time during attendance.
- Reduces proxy attendance through GPS verification.
- Provides immediate attendance confirmation.
- Makes attendance records easy to view and manage.
- Improves the overall attendance experience for both students and lecturers.

## Responsible Data Message

AttendQR only collects the minimum information required for attendance verification, such as user identity, attendance status, and GPS location during check-in. The collected data is used only for attendance management and is not shared with unauthorized parties.
